# Grafime
## _Crea tus grafitis de manera libre y gratuita_

## Features

- Dibujar en el canvas
- Cambiar el color del pincel
- Cambiar entre diferentes estilos de pinceles usados en el grafiti
- Limpiar el canvas
- Guardar como imagen tu dibujo
- Cambiar el grosor de la linea de tu pincel
## Tech

- [Angular] - Framework web!
- [Antigravity] - El mejor editor de codigo del mundo mundial 😁
- [CSS] - Lenguaje de estilos.

## Installation

Grafime requiere [Node.js](https://nodejs.org/) v18+.

Instalar dependencias:

```sh
cd grafime
npm i
npm start
```
Por ultimo entrar a http://localhost:4200 - que es el servidor local para desarrollo.
